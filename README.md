## Project Description
A Java-based e-commerce application that manages multiple product categories and generates consolidated invoices.

## Main Features
- Physical product management
- Digital software license management
- Perishable food item management
- Automatic GST calculation
- Shipping cost calculation
- Unique tracking ID generation
- Digital license key generation
- Unified invoice generation
